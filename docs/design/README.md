# Design do produto

O design atual de **CRYPTO FORECASTING** é o v3 — **Observatório Vivo**.

## Fonte normativa

[Design.md](Design.md) é a única fonte de verdade de UI/UX. Ele reúne direção de arte, tokens, tipografia, movimento, vídeo do Login, telas, estados, visualização de dados, responsividade, acessibilidade e critérios de aceite.

Os PNGs em [mockups/current/](mockups/current/) são referências visuais. Quando imagem e texto divergirem, `Design.md` vence.

## Fluxo para implementação

1. Ler `Design.md` por inteiro.
2. Abrir o mockup da tela em `mockups/current/`.
3. Implementar preservando o comportamento existente e as regras normativas.
4. Validar os critérios de aceite da seção 18 de `Design.md`.

Mockups ou documentos anteriores ao v3 não pertencem à especificação atual.
